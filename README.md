# 移动原声带 · Motion Score

移动原声带是一个面向跑步、驾车和室内运动的音乐陪伴原型。比如夜跑时，产品设想用不同节奏的音乐提示出发、稳定配速和接近终点，减少查看手机的次数。结束后，可以把路线、时长和歌单整理成一张原声带卡片，方便回顾或复用。

## 快速体验

下载离线版并完整解压，用浏览器打开 `motion-score-prototype.html`。点左侧目录或右侧操作按钮，即可浏览 14 个设计页面，无需联网或启动服务。[下载离线原型 ZIP](https://github.com/xu13791666851-sudo/Motion-score/raw/refs/heads/main/%E7%A7%BB%E5%8A%A8%E5%8E%9F%E5%A3%B0%E5%B8%A6-%E7%A6%BB%E7%BA%BF%E5%8E%9F%E5%9E%8B.zip)

## 原型里可以体验什么

- **户外路线**从首页选择跑步或驾车，查看深圳湾到人才公园的演示路线，再进入播放页体验切歌、计时和进度变化。
- **室内训练**从「运动」进入跑步机或健身流程，体验按训练时间展示进度，完成后查看训练卡片。
- **路线卡片**支持演示发布流程。到「发现」浏览示例路线，再用「复用这段原声带」回到路线设置。

当前版本使用示例路线、歌单和社区数据，QQ 音乐授权与歌单生成均为模拟。公开仓库中的歌单只包含歌曲信息，播放页演示计时和切歌。[音频素材说明](assets/audio/README.md)

## 本地运行交互版

先安装 Python 3，再在仓库根目录运行以下命令。

```bash
python mock_api.py
```

浏览器打开 `http://127.0.0.1:43821/`，首页会跳转到交互版。服务使用 Python 自带的功能，无需额外安装依赖。
